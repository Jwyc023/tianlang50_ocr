# 天狼50 OCR 监控系统

## 项目简介

这是一个基于OCR技术的股票市场监控系统，专门用于实时监控天狼50软件中的8个主要指数板块的主力等级和级别信息。系统通过屏幕截图和OCR识别技术，自动提取各板块的数值数据，并生成监控报告。

## 核心功能

### 📊 多板块监控
- **中证1000** - 主力等级和级别监控
- **中证500** - 主力等级和级别监控  
- **沪深300** - 主力等级和级别监控
- **上证50** - 主力等级和级别监控
- **上证指数** - 主力等级和级别监控
- **深证成指** - 主力等级和级别监控
- **科创50** - 主力等级和级别监控
- **创业板指** - 主力等级和级别监控

### 🚀 高性能特性
- **快速截图** - 使用MSS库实现毫秒级屏幕捕获
- **并行处理** - 多线程同时处理8个板块数据
- **智能OCR** - 针对不同数据类型优化的识别算法
- **实时监控** - 连续监控并记录数据变化

### 📈 数据输出
- **CSV格式** - 结构化数据存储，便于分析
- **截图保存** - 自动保存监控截图用于验证
- **日志记录** - 详细的运行日志和错误记录
- **失败追踪** - 识别失败的截图单独保存

## 技术架构

### 🖥️ 核心技术栈
- **Python 3.x** - 主要开发语言
- **OpenCV** - 图像处理和预处理
- **Tesseract OCR** - 文字识别引擎
- **MSS** - 高性能屏幕截图
- **ThreadPoolExecutor** - 多线程并行处理

### 🔧 关键组件

#### 1. 监控引擎 (`monitor_fast.py`)
- 高性能全屏截图
- 智能图像预处理
- 多线程OCR识别
- 数据验证和清洗
- 结果输出和存储

#### 2. ROI配置系统 (`rois.json`)
- 预定义监控区域坐标
- 支持8个板块的独立配置
- 主力等级和级别分离配置
- 动态调整支持

#### 3. 校准工具 (`calibrate_rois.py`)
- 交互式ROI区域调整
- 实时预览和验证
- 配置保存和加载

## 数据格式

### 📊 CSV数据字段
```csv
timestamp,中证1000_主力等级,中证1000_级别,中证500_主力等级,中证500_级别,沪深300_主力等级,沪深300_级别,上证50_主力等级,上证50_级别,上证指数_主力等级,上证指数_级别,深证成指_主力等级,深证成指_级别,科创50_主力等级,科创50_级别,创业板指_主力等级,创业板指_级别,结论,截图文件
```

### 🏷️ 级别标识
- **AAA** - 最高级别
- **AA** - 高级别  
- **A** - 中级别
- **B** - 低级别
- **C** - 最低级别

### 📈 主力等级
- 数值范围：-∞ 到 +∞
- 正数表示主力流入
- 负数表示主力流出

## 配置说明

### 📍 ROI区域配置
每个板块包含两个监控区域：
- **power** - 主力等级数值区域
- **grade** - 级别标识区域

格式：`[x, y, width, height]`

### 🔧 OCR参数优化
- **主力等级**：数字识别模式，2倍放大
- **级别标识**：字符识别模式，3倍放大
- **自适应阈值**：根据图像特征自动调整

## 故障排除

### ❌ 常见问题
1. **识别失败** - 检查ROI区域是否正确
2. **截图错误** - 确认天狼50软件在前台
3. **OCR错误** - 验证Tesseract安装路径

### 🔍 调试方法
- 查看 `data/logs/` 中的日志文件
- 检查 `data/failed_screenshots/` 中的失败截图
- 使用校准工具重新调整ROI区域
