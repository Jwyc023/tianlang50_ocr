# 时间轴监控使用说明

## 功能概述

时间轴监控工具能够自动移动鼠标沿着时间轴，记录每一分钟8个板块的主力等级和级别数据。

### 工作原理

1. 鼠标自动在时间轴上从左到右移动（9:30 → 15:00）
2. 每移动到一个时间点，程序会：
   - 等待界面更新显示该时刻的数据
   - 截图并使用OCR识别8个板块的主力等级和级别
   - 计算信号（做多/做空/观望）
   - 保存到CSV文件
3. 自动处理所有时间点（约330个时间点，每分钟一个）

## 使用步骤

### 第一步：校准时间轴坐标

在首次使用前，需要标定时间轴的位置参数：

```bash
cd tools
python calibrate_timeline.py
```

按照提示完成以下操作：

1. **标定起点（9:30）**
   - 将鼠标移动到时间轴的9:30位置
   - 按Enter键记录坐标

2. **标定终点（15:00）**
   - 将鼠标移动到时间轴的15:00位置
   - 按Enter键记录坐标

3. **标定监控区域**
   - 标定板块显示区域的上边界
   - 标定板块显示区域的下边界

4. **确认时间范围**
   - 默认为09:30~15:00
   - 可根据需要修改

校准完成后，配置会保存到 `data/timeline_config.json`

### 第二步：测试校准结果（可选）

运行测试功能验证坐标是否准确：

```bash
python calibrate_timeline.py
# 选择选项 2: 测试校准结果
```

程序会自动移动鼠标到起点、中点、终点，请确认位置是否正确。

### 第三步：测试运行（推荐）

首次使用建议先进行测试，只采集几个时间点：

```bash
cd src
python monitor_timeline.py --test
```

这将只采集5个均匀分布的时间点，用于验证：
- 鼠标移动位置是否准确
- OCR识别是否正常
- 数据记录是否正确

检查输出的CSV文件，确认数据准确后再进行完整采集。

### 第四步：完整运行

确保：
- 界面已打开并显示时间轴
- 时间轴完整可见（9:30到15:00）
- 8个板块的显示区域可见

运行完整监控：

```bash
cd src
python monitor_timeline.py
```

程序会：
1. 显示配置信息
2. 倒计时3秒
3. 自动开始采集数据（约330个时间点）
4. 总耗时约10-15分钟

**命令行选项**：

```bash
# 测试模式，只采集5个点
python monitor_timeline.py --test

# 测试模式，采集10个点
python monitor_timeline.py --test --test-points 10

# 指定输出文件路径
python monitor_timeline.py --output ../data/my_data.csv

# 组合使用
python monitor_timeline.py --test --output ../data/test.csv
```

**中断方法**：将鼠标移动到屏幕左上角

## 输出文件

### CSV文件格式

输出文件保存在：`data/timeline_YYYYMMDD_HHMMSS.csv`

文件包含以下列：

| 列名 | 说明 |
|------|------|
| 时间 | HH:MM格式，如09:30 |
| 中证1000_主力等级 | 数值 |
| 中证1000_级别 | A/AA/AAA/-A/-AA/-AAA等 |
| 中证500_主力等级 | 数值 |
| 中证500_级别 | A/AA/AAA/-A/-AA/-AAA等 |
| ... | 其他6个板块 |
| 信号 | 做多/做空/观望 |

示例：

```csv
时间,中证1000_主力等级,中证1000_级别,中证500_主力等级,中证500_级别,...,信号
09:30,15.5,AA,12.3,A,...,做多
09:31,16.2,AAA,13.1,AA,...,做多
09:32,14.8,A,11.5,A,...,观望
```

## 配置文件说明

### timeline_config.json

```json
{
  "timeline": {
    "start_x": 100,      // 时间轴起点X坐标（9:30）
    "end_x": 1800,       // 时间轴终点X坐标（15:00）
    "y": 600,            // 时间轴Y坐标
    "monitor_area_y1": 400,  // 监控区域上边界
    "monitor_area_y2": 700   // 监控区域下边界
  },
  "time_range": {
    "start": "09:30",
    "end": "15:00"
  }
}
```

## 注意事项

### 使用前

1. **确保OCR已配置**
   - 需要安装Tesseract OCR
   - 配置路径：参考`src/monitor_fast.py`

2. **确保ROI已校准**
   - 8个板块的主力等级和级别识别区域
   - 配置文件：`data/rois.json`
   - 校准工具：`tools/calibrate_rois.py`

3. **安装依赖**
   ```bash
   pip install pyautogui opencv-python numpy pytesseract mss
   ```

### 使用中

1. **不要移动或操作电脑**
   - 监控期间鼠标会自动移动
   - 不要干扰程序运行
   - 不要切换窗口

2. **保持界面稳定**
   - 确保时间轴界面始终可见
   - 不要调整窗口大小或位置
   - 不要遮挡显示区域

3. **监控进度**
   - 控制台会实时显示当前处理的时间点
   - 显示识别结果和信号
   - 如有错误会记录到CSV中

4. **中断程序**
   - 正常方法：将鼠标移到屏幕左上角
   - 紧急方法：Ctrl+C

### 性能说明

- **采集时间**：约330个时间点，每个点约1-2秒，总计约10-15分钟
- **准确率**：取决于OCR识别准确率和界面显示质量
- **资源占用**：CPU和内存占用较低

## 常见问题

### Q1: 鼠标移动位置不准确

**解决方法**：
- 重新运行`calibrate_timeline.py`校准
- 确保时间轴位置没有变化
- 检查屏幕分辨率是否改变

### Q2: OCR识别错误率高

**解决方法**：
- 检查界面显示清晰度
- 调整屏幕亮度和对比度
- 确保ROI区域准确（运行`calibrate_rois.py`）
- 参考`OCR_优化方案.md`优化识别参数

### Q3: 程序运行很慢

**原因**：
- OCR识别需要时间（每个板块约0.2-0.5秒）
- 8个板块总计约2-4秒
- 已使用并行处理优化

**优化方法**：
- 使用更快的电脑
- 减少同时运行的其他程序
- 考虑使用更快的OCR引擎（PaddleOCR/EasyOCR）

### Q4: 数据有缺失

**可能原因**：
- 界面显示延迟
- OCR识别失败
- 鼠标移动过快

**解决方法**：
- 增加等待时间：修改`move_mouse_to_time()`中的`time.sleep(0.3)`
- 检查CSV文件，手动补充缺失数据
- 对特定时间段重新采集

## 高级使用

### 自定义时间范围

编辑配置文件或在校准时设置：

```json
{
  "time_range": {
    "start": "10:00",
    "end": "14:00"
  }
}
```

### 批量处理

如需处理多天的数据，可以：

1. 准备多个时间轴界面
2. 逐个切换并运行监控脚本
3. 输出文件会自动按时间戳命名

### 数据分析

采集完成后，可使用Python进行数据分析：

```python
import pandas as pd

# 读取数据
df = pd.read_csv("data/timeline_20250924_100000.csv")

# 统计信号分布
print(df['信号'].value_counts())

# 分析某个板块的趋势
import matplotlib.pyplot as plt
plt.plot(df['时间'], df['中证1000_主力等级'])
plt.show()
```
